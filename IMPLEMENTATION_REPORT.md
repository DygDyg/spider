## Реализованные SVG-карты

### Количество карт:
- **52 SVG-карты** встроены в код (все комбинации 4 мастей × 13 рангов)

### Путь к изображениям:
- Карты встроены в `src/components/Card/cardSVGs.ts`
- Генерируются динамически через функции:
  - `getNumberCardSVG(suit, rank, color)` — для карт 2-10
  - `getAceCardSVG(suit, color)` — для тузов
  - `getFaceCardSVG(suit, rank)` — для J, Q, K

### Компоненты, использующие OpenDecks:
- **CardFace.tsx** — основной компонент отрисовки лицевой стороны карт
- **Card.tsx** — использует CardFace для отображения карт

### Особенности SVG-карт:

#### Фигурные карты (J, Q, K):
- **Многоцветные иллюстрации** с детализированными лицами, одеждой, коронами
- **Валет (Jack)**: шляпа с пером, туника, меч в руке, символ масти на груди
- **Дама (Queen)**: корона с драгоценностями, платье, ожерелье, цветок в руке
- **Король (King)**: большая корона, мантия, скипетр, держава, горностаевая отделка
- **Сохранение оригинального многоцветного оформления** — лица, одежда, декоративные элементы
- **Точечное изменение цветов** только для символов мастей и индексов

#### Числовые карты (2-10):
- **Классическая раскладка** символов мастей
- **Симметричное расположение** с правильным количеством символов
- **Верхние символы** ориентированы нормально, нижние — перевёрнуты на 180°

#### Тузы:
- **Крупный центральный символ** масти (увеличенный в 2.5 раза)
- **Классическое оформление** с одним большим символом

#### Поддержка тем:
- **Светлая тема**: чёрные масти (#1a1a2e), красные масти (#dc2626)
- **Тёмная тема**: чёрные масти становятся серебристо-голубыми (#A8C7FA), красные — ярко-красными (#FF6B6B)
- **Цвета передаются через параметр** `color` в функции генерации SVG
- **Белые участки, лица и декоративные детали сохраняются** без изменений

## Реализованные анимации

### Где вызывается AnimationManager/FlipAnimator:

#### 1. Первоначальная раздача (animateInitialDeal)
- **Где**: `GameBoard.tsx`, useEffect при первом монтировании
- **Что делает**: Анимация раздачи 54 карт из колоды по колонкам
- **Параметры**: 40ms между картами, 300ms длительность полёта
- **Звук**: `cardDeal` при каждой карте

#### 2. Перемещение карт (FLIP-анимация)
- **Где**: `GameBoard.tsx`, useEffect при изменении gameState
- **Что делает**: Плавное перемещение карт между колонками
- **Техника**: FLIP (First, Last, Invert, Play)
- **Параметры**: 250ms, easing `cubic-bezier(0.22, 1, 0.36, 1)`
- **Звук**: `cardMove` + `cardPlace`

#### 3. Раздача из резерва (animateStockDeal)
- **Где**: `GameBoard.tsx`, useEffect при уменьшении stock
- **Что делает**: Анимация раздачи 10 карт из резерва
- **Параметры**: 50ms между картами, 300ms длительность
- **Звук**: `cardPlace` при каждой карте

#### 4. Переворот карт (checkCardFlips)
- **Где**: `GameBoard.tsx`, useEffect при изменении gameState
- **Что делает**: 3D-переворот карт при изменении faceUp
- **Параметры**: 400ms, CSS-анимация `cardFlip3D`
- **Звук**: `cardFlip`

#### 5. Завершение последовательности (animateSequenceComplete)
- **Где**: `GameBoard.tsx`, useEffect при увеличении completedSets
- **Что делает**: Подсветка, сбор в стопку, перемещение в область завершённых
- **Параметры**: 400ms, последовательная анимация карт
- **Звук**: `sequenceComplete`

#### 6. Победа (animateVictory)
- **Где**: `GameBoard.tsx`, useEffect при gameWon
- **Что делает**: Карты разлетаются в разные стороны с вращением
- **Параметры**: 1500ms, конфетти
- **Звук**: `victory`

#### 7. Недопустимый ход
- **Где**: `useGame.ts`, makeMove
- **Звук**: `invalidMove`

#### 8. Отмена/повтор хода
- **Где**: `useGame.ts`, undo/redo
- **Звук**: `undo`/`redo`

#### 9. Кнопки интерфейса
- **Где**: `Toolbar.tsx`, все кнопки
- **Звук**: `buttonClick`

## Технические детали

### Архитектура анимаций:

1. **FLIP-техника**:
   - First: Захват позиций перед изменением состояния
   - Last: Получение новых позиций после перерисовки React
   - Invert: Вычисление разницы и применение обратного transform
   - Play: Анимация к конечной позиции с easing

2. **Оптимизации**:
   - Использование `transform` и `opacity` (GPU-ускорение)
   - Временное применение `will-change`
   - Избегание React re-render во время анимации
   - Очистка стилей после завершения

3. **Синхронизация**:
   - Блокировка взаимодействия во время анимации раздачи
   - Предотвращение конфликтов параллельных анимаций
   - Корректная обработка быстрых последовательных действий

### Звуковая система:

1. **Web Audio API**:
   - Все звуки синтезируются программно
   - Нет внешних файлов
   - Мгновенная загрузка
   - Работа без интернета

2. **Типы звуков**:
   - Шум (белый шум через AudioBuffer)
   - Осцилляторы (sine, square, triangle)
   - Фильтры (bandpass, lowpass, highpass)
   - Огибающие (exponential, linear ramps)
