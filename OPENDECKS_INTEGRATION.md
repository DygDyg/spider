## Что нужно сделать для завершения

### Шаг 1: Загрузить SVG-файлы

Выполните команду:
```bash
chmod +x download-opendecks.sh
./download-opendecks.sh
```

Это загрузит все 52 SVG-файла в `public/cards/`:
- `public/cards/spades/` - 13 файлов
- `public/cards/hearts/` - 13 файлов
- `public/cards/diamonds/` - 13 файлов
- `public/cards/clubs/` - 13 файлов

## Технические детали

### Масштабирование
- Используется `object-fit: contain` для сохранения пропорций
- `preserveAspectRatio="xMidYMid meet"` для встроенных SVG
- Карты не деформируются при изменении размера

### Тёмная тема
- Чёрные масти (♠, ♣) → серебристо-голубой (#A8C7FA)
- Красные масти (♥, ♦) → ярко-красный (#FF6B6B)
- Фигурные карты (J, Q, K) сохраняют оригинальные цвета
- Числовые карты и тузы перекрашиваются

### Загрузка
- SVG загружаются через `fetch()` в runtime
- Поддерживается `import.meta.env.BASE_URL` для GitHub Pages
- Обработка ошибок и индикатор загрузки

## Проверка

### Автоматическая проверка

Создан скрипт для проверки:
```bash
# Проверить количество файлов
find public/cards -name "*.svg" | wc -l
# Должно быть: 52

# Проверить структуру
tree public/cards

# Проверить валидность SVG
for file in public/cards/*/*.svg; do
  if ! grep -q "<svg" "$file"; then
    echo "Invalid SVG: $file"
  fi
done
```
