# Пасьянс Паук (Spider Solitaire)

Полноценная браузерная игра «Пасьянс Паук» с современным интерфейсом и умной системой подсказок.

## 🎮 Возможности

### Игровой процесс
- **Три уровня сложности**: 1 масть (лёгкий), 2 масти (средний), 4 масти (сложный)
- **Классические правила** Spider Solitaire
- **104 карты** в каждой партии
- **Автоматическая сборка** полных последовательностей (K→A одной масти)
- **Раздача из резерва** (50 карт, 5 раздач по 10 карт)

### Управление
- **Перетаскивание мышью** (Drag & Drop)
- **Сенсорное управление** для мобильных устройств
- **Клик по карте** — выбор, клик по цели — перемещение
- **Двойной клик** — автоматический ход
- **Горячие клавиши**:
  - `Ctrl+Z` — отмена хода
  - `Ctrl+Y` / `Ctrl+Shift+Z` — повтор хода
  - `H` — подсказка
  - `N` — новая игра
  - `Esc` — закрытие модальных окон

### Умная система подсказок
- **Приоритеты ходов**:
  1. Открытие закрытых карт (высший приоритет)
  2. Завершение одномастных последовательностей
  3. Создание/удлинение одномастных последовательностей
  4. Освобождение колонок
  5. Создание новых возможностей
- **Поиск на 2 хода вперёд** с оценкой будущих состояний
- **Исключение циклов** через хеширование состояний
- **Визуальная стрелка** от источника к цели с анимацией
- **Переключение между подсказками** при повторном нажатии

### Визуальное оформление
- **Единый SVG с viewBox** для всех карт — пропорции сохраняются при любом масштабе
- **Классические игральные карты**:
  - Числовые карты (2-10) с симметричной раскладкой символов мастей
  - Фигурные карты (J, Q, K) с детализированными SVG-изображениями
  - Туз с большим декоративным символом масти
- **Четыре темы оформления**:
  - Классическая зелёная
  - Тёмная современная (с серебристо-голубыми чёрными мастями)
  - Синяя в стиле Windows
  - Светлая минималистичная
- **Плавные анимации** с поддержкой `prefers-reduced-motion`

### Дополнительные функции
- **Отмена/повтор ходов** (Undo/Redo) с полной историей
- **Автосохранение** в localStorage
- **Статистика** для каждого уровня сложности
- **Адаптивный дизайн** для экранов от 320px до 1920px+
- **Русский интерфейс**
- **Работа офлайн** (статический сайт)

## 🚀 Запуск проекта

### Требования
- Node.js 16+ 
- npm или yarn

### Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр собранной версии
npm run preview
```

После запуска откройте браузер по адресу, указанному в терминале (обычно `http://localhost:3000`).

## 🎯 Правила игры

### Перемещение карт
- Одиночную открытую карту можно положить на карту с рангом на единицу выше (независимо от масти)
- Группу карт можно переносить только если все карты открыты, одной масти и идут по убыванию
- На пустую колонку можно перенести любую допустимую последовательность

### Раздача из резерва
- Раздача возможна только если нет пустых колонок
- Каждая раздача добавляет по одной карте в каждую из 10 колонок

### Автоматическая сборка
- Когда образуется последовательность K→Q→J→10→9→8→7→6→5→4→3→2→A одной масти, она автоматически удаляется
- При необходимости открывается закрытая карта

### Победа
- Собрать все 8 полных последовательностей

## 🧪 Тестирование

Тесты проверяют:
- Создание колоды из 104 уникальных карт
- Корректность начальной раздачи
- Правила перемещения карт
- Автоматическую сборку последовательностей
- Инвариант: сумма карт всегда = 104
- Отсутствие циклов в подсказках
- Приоритеты подсказок
- Законность всех предлагаемых ходов
- Стабильность генерации по seed

## 🔧 Технологии

- **React 18** с TypeScript
- **Vite** для сборки
- **CSS3** с переменными и `aspect-ratio`
- **SVG** для графики карт
- **Pointer Events API** для управления
- **localStorage** для сохранения

## 📊 Система очков

- Начальные очки: 500
- Каждый ход: -1 очко
- Каждая собранная последовательность: +100 очков
- Очки могут быть отрицательными

## 🎨 Темы оформления

Все темы используют CSS-переменные и переключаются мгновенно:

1. **Classic** — тёмно-зелёное сукно, белые карты
2. **Dark** — тёмно-синий фон, серебристо-голубые чёрные масти
3. **Blue** — синий фон в стиле Windows
4. **Light** — светлая минималистичная тема

## 📱 Адаптивность

Игра корректно работает на:
- Десктопах (1920×1080 и выше)
- Планшетах (1024×768, 768×1024)
- Смартфонах (от 320×568)
- Устройствах с высоким DPI

## 🐛 Известные ограничения

- Случайная раскладка не обязательно является решаемой
- Поиск подсказок ограничен 2 ходами вперёд для производительности
- Звуковые эффекты не реализованы (можно добавить позже)
